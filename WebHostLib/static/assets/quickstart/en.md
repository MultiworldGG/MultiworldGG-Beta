# Quickstart Guide

New to MultiworldGG? This page walks you from zero to your first game in as
stright of a line as possible. It takes about ten minutes if I wrote this 
correctly, or about 45 minutes if I missed something obscure or you got distracted.
If you get stuck at any point, the [Learn hub](/learn/en) has
deeper guides, and the community on [Discord](https://discord.multiworld.gg) is
happy to help.

==TL;DR: Read the highlighted bits==

## Choose a game

MultiworldGG randomizes dozens of games and links them into a single shared
multiworld.  Many of them can be played without downloading the software!

==If a friend has dragged you into the chaos, find out if you need a yaml file
or if they have a lobby opened for you to join.==

1. Browse the [supported games list](/games) and look for a game you own and want
   to play.

2. You'll see 4 links as follows:
  * **Game Page**: Notes on how the game is randomized
  * ==**Setup Guides**: How to install/run the game mod.==
  * **Wiki**: Link to the Game's page on the APWorlds Wiki
  * ==**Options Page**: Choose your player name and what's randomized (YAML)==
  * **Advanced Options**: Put more rando in your rando every time you rando.
3. ==Open **Setup Guides** and **Options Page** in new tabs==

### ~~Read~~ Skim the game's setup guide

Every game has its own setup steps - which legally obtained copy of the game or
additional software you need, which client to use, and how to connect.

==You're looking for 2 things:==
1. ==Can I run this mod (Windows/Mac/Phone/Browser/Your Dad's Old 3DS/etc)==
2. ==Do I need to install the Multiworld Software or any other Software==

> You should now have the following information:
> - [ ] Solo test, yaml file, or lobby invite?
> - [ ] Game Name
> - [ ] Do I need Multiworld Software?
> - [ ] Do I need anything special to run the game?

#### Download and install MultiworldGG *IF NEEDED*

1. ==Open the [Downloads page](/downloads) and grab the installer for your operating
   system.== You can also download the latest build directly from the
   [GitHub releases page](https://github.com/MultiworldGG/MultiworldGG-Beta/releases/latest).
2. ==Run the installer, skip the game install choice, and read the licenses thoroughly==

We say that because you're already skimming this, aren't you?

#### Download and install other necessary bits of the Game's Mod *IF NEEDED* 

Details will be on the game's setup page.

> Grab this from the page too:
> - [ ] Does the game require a patch?

### Go to the Options Page (yaml)

==*If you have a lobby link, click on that first and join with your name.*==

1. ==Enter your username in the 'Player' section==
2. **Press "Export" at the bottom if someone has asked you for your yaml file**
3. **Press "Generate Single-Player Game" if you're trying this out as a test**
4. **Press "Add to Active Lobby" if you were given a lobby link**

> You'll notice there are a LOT of options here, and I intentionally skipped
> having you fill them all out.  This is **intentional**.  I know you were
> on the SRC leaderboard and are very skilled, but the defaults are set to
> give a fun experience. Tweak them after you've had your first experience.

It looks cooler when you make something easy look easy, too

## Play!

> Self generated? Click on the Go to Room link for your information

You'll be provided with a link to the room. Click this link when it's given to you.

==Find the server name (multiworld.gg), port number (38281), and your name on the list.
If you need a patch it will also be on this page. Download it and double click to open.==

Once it's opened, you should have a client that you can enter the server name, port number
and your player name (or slot name, or user name). Double check your game's setup guide to 
finish this off and start the fun!

> TL;DR?
>
> - Click on Game
> - Make YAML
> - Get room information
> - Open patch
> - Open Game and MultiworldGG Client
> - Go to Burger King (you're done so early it'll take ages for everyone else to catch up)
